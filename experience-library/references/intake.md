# 首次输入引导

只在用户尚未提供材料时使用。已有叙述、简历或文档就直接整理，不要求重填。

你可以直接讲工作、项目、校园活动或单独一项技能，也可以发已有简历和补充说明，不必先写成简历格式。能记得的话，讲讲大概时间与身份、你本人做了什么、遇到什么问题或限制、最后交付及实际使用情况。相关人数、比例、频次和统计范围也可以照原样说；不确定就说明不确定，不用为了完整编数字。

团队工作请尽量区分本人完成的部分。技能可以讲实际用它做过什么、哪些能独立完成。普通经历和未成功的尝试也能保留。

我会先整理一份连贯初稿，只集中问会影响事实理解或后续取材的少数问题。你可以补充、修改、拒绝或跳过，再由我合并成一份经历库。
