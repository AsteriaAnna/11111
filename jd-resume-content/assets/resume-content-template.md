# 简历内容稿模板

这是可调整的板块与格式示例，不是必须填满的表单。依据 JD 和经历库增删、改名、调整顺序；成稿删除所有方括号提示和空栏目。项目更强可将项目经历放在实习经历前；没有实习就不设实习板块；教育信息可前置、后置或简写。此稿只处理内容，表格、字体和视觉排版留待后续环节。

```markdown
# [姓名，如已提供]｜[目标岗位或求职方向]

[联系方式；仅写已提供的信息]
[一句可由下方经历证明的定位：我是谁＋最值得看的岗位相关实力]
[相关且已提供的 GitHub、作品或其他链接，可选]

## [实习经历／项目经历：根据重要性决定谁先出现]

### [组织或项目名称]｜[真实职位或本人角色]｜[起止时间]
[必要时：一句项目价值、服务对象、规模或本人职责。常规岗位可省略。]
[技术项目必要时：技术栈或实现环境；也可融入下方要点。]
- **[真实且对口的模块／流程／技能标签，可选]：**[本人做法、产物，以及原文支持的结果]
- [另一项不同的贡献；简单经历可以只写一条，不必加标签]

## [项目经历／实习经历：有相关内容时保留]

### [组织或项目名称]｜[真实身份]｜[起止时间]
- [按该经历最合适的阅读路线写]

## [教育背景：位置可调整]

[学校]｜[专业与学位]｜[起止或预计毕业时间]
[相关成绩、课程或荣誉；有用时填写]

## [技能与资质：有相关内容时保留]

- **[能力主题]：**[真实工具、技能及必要的使用场景]
- **[语言／证书]：**[有价值的具体成绩或资格]
```

正文之外仅在必要时另附简短编辑说明，用来提醒尚需确认的关键信息或解释有争议的取舍；不要固定生成“岗位缺口”栏目，也不要把工作备注放进简历正文。
